# Getting help

| Need | Where |
|---|---|
| A question about using the site | [Discussions → Q&A](https://github.com/APESCIC/APES.Newsroom/discussions/categories/q-a) |
| A problem with your own account or emails | The contact or help links on https://www.apesnews.org.uk/ (please don't post personal details publicly) |
| An idea or feedback | Discussions → Ideas or Feedback |
| A bug in the app | [Open an issue](https://github.com/APESCIC/APES.Newsroom/issues/new/choose) |
| A security problem | [Report it privately](https://github.com/APESCIC/APES.Newsroom/security/advisories/new) |
| A Code of Conduct concern | legal@apes.org.uk |

The APES team replies when it can; there is no guaranteed response time for public questions.
