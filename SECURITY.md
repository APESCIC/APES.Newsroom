# Security policy

APES Newsroom is built and run by the Association of Protecting Exotic Species CIC (APES) for its own use; the code is public.

## Supported versions
Only the latest release (currently v1.28.0) receives security fixes. The live site at https://www.apesnews.org.uk/ always runs a supported release.

## Reporting a vulnerability
Please report vulnerabilities **privately** using GitHub's private vulnerability reporting:
https://github.com/APESCIC/APES.Newsroom/security/advisories/new

Do not open a public issue, pull request or Discussion about a vulnerability, and do not include real passwords or personal data in your report.

Please include: what is affected, steps to reproduce, the impact you think it has, and any suggested fix.

## What to expect
- Acknowledgement within 5 working days.
- An initial assessment within 10 working days.
- A fix, or a plan with a timeline, within 30 days for confirmed issues.
- Credit in the advisory if you would like it.

## Scope
In scope: this repository's code and the live app at www.apesnews.org.uk.
Out of scope: third-party services (Cloudron, Mailgun, Stripe, GitHub), denial-of-service and load testing, social engineering, physical attacks, and reports from automated scanners without a demonstrated impact.

Please test only against your own accounts and never access, change or delete other people's data.
